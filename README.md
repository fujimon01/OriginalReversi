# OriginalReversi

## 概要
難易度選択可能なAI対戦オセロゲーム。プレイヤーが直感的に遊べるよう、UI/UXデザインを重視して開発しました。

## なぜ作ったのか
オセロは戦略性の高いゲームですが、**初心者にとってはルールの複雑さやUI操作がハードルになることが多い**と考えました。このプロジェクトでは「分かりやすいUI」を意識することで、初心者から上級者まで快適に遊べるゲーム設計を目指しました。

プログラミング講師として「分かりやすさ」の重要性を実感していることから、そのスキルをゲーム開発に活かす良い機会と考えました。

## 何を重視したか
- **UI/UXデザイン**：複雑な盤面操作を、直感的かつ分かりやすく
- **ユーザー体験**：初心者でもストレスなく遊べることを最優先
- **難易度調整**：AI難易度によって、初心者から上級者まで対応

## 主な機能

### 1. AI難易度選択
```
Easy / Normal / Hard
```
プレイヤーのスキルレベルに応じてAIの思考深度を変更。
初心者でも達成感を感じられるように設計。

### 2. 直感的なUI/UX
- **ボタン配置**：「開始」「リセット」「設定」など主要操作を画面上部に集約
- **ビジュアルフィードバック**：置ける場所が視覚的にわかるようにハイライト表示
- **操作の明確性**：「次は何をすればいいのか」が一目瞭然

### 3. ゲームプレイ
- オセロの基本ルール準拠
- 盤面状態のリアルタイム更新
- スコア表示（黒・白の駒数）

## 技術スタック
- **Unity**：2022 LTS
- **言語**：C#
- **ターゲット**：PC / WebGL 対応

## 工夫した点

### UIデザイン
初心者がオセロに興味を持っても、「どこをクリックすればいいのか」という疑問を持つことが多い。
そこで、以下を工夫しました：

1. **操作ボタンの視認性向上**
   - 主要操作（ゲーム開始、難易度選択、リセット）を見やすく配置
   - テキストサイズを大きく、色をコントラスト高めに設定

2. **盤面操作の直感性**
   - 置ける場所が自動的にハイライトされるため、初心者でも置ける場所がすぐわかる
   - クリック可能な領域を視覚的に明示

3. **ステータス表示の充実**
   - 現在のターン（黒/白）
   - 各プレイヤーの駒数
   - ゲーム終了時の勝敗表示

### AIアルゴリズム
難易度に応じて、AI の思考ロジックを調整：
- **Easy**：ランダムに置ける場所を選択
- **Normal**：評価関数を使った標準的な思考
- **Hard**：複数手先の読みを実装

### コード構造
- `GameManager.cs`：ゲーム状態管理
- など

## セットアップ方法

### 必要環境
- Unity 2022 LTS 以上
- C# 9.0 以上

### インストール
```bash
git clone https://github.com/YourUsername/OriginalReversi.git
cd OriginalReversi
```

### 実行方法
1. Unity Hub を開く
2. 「プロジェクトを開く」から このリポジトリのフォルダを選択
3. Unity エディタで `Assets/Scenes/Main.unity` を開く
4. Play ボタンを押してゲーム開始

## ゲームの遊び方

1. **難易度を選択**
   - Easy / Normal / Hard から選択
   
2. **ゲーム開始**
   - 「Start Game」ボタンをクリック
   - 黒（プレイヤー）のターンからスタート

3. **駒を置く**
   - 置ける場所がハイライトで表示される
   - その位置をクリックして駒を置く

4. **ゲーム終了**
   - 盤面がいっぱいになると自動終了
   - 勝敗と最終スコアを表示

5. **リセット**
   - 「Reset」ボタンで新しいゲームを開始
